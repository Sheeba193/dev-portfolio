## 🚀 Quick Start

### Prerequisites

```
✓ Node.js v14 or higher
✓ npm or yarn package manager
✓ Git
✓ Code editor (VS Code recommended)
```

### Installation & Setup

**Step 1:** Clone the repository
```bash
git clone https://github.com/Sheeba193/dev-portfolio.git
cd dev-portfolio
```

**Step 2:** Install dependencies
```bash
npm install
# or
yarn install
```

**Step 3:** Start development server
```bash
npm start
# or
yarn start
```

**Step 4:** Open in browser
```
http://localhost:3000
```

## 🔧 Configuration

### Environment Variables

Create `.env` file in project root:

```env
# Development
REACT_APP_ENV=development
REACT_APP_API_URL=http://localhost:3001

# Email Service (if applicable)
REACT_APP_EMAIL_SERVICE=emailjs
REACT_APP_EMAIL_KEY=your_email_key

# Analytics (optional)
REACT_APP_GOOGLE_ANALYTICS_ID=your_ga_id

# Social Media Links
REACT_APP_GITHUB_URL=https://github.com/Sheeba193
REACT_APP_LINKEDIN_URL=https://linkedin.com/in/sheeba193
REACT_APP_TWITTER_URL=https://twitter.com/Sheeba193
```

### Production Configuration

```env
# Production
REACT_APP_ENV=production
REACT_APP_API_URL=https://api.example.com

# Analytics
REACT_APP_GOOGLE_ANALYTICS_ID=your_production_ga_id
```

## 🎨 Customization

### Update Personal Information

Edit `src/data/` files to customize your portfolio:

**projects.json**
```json
{
  "projects": [
    {
      "id": 1,
      "title": "Your Project",
      "description": "Project description",
      "image": "/images/projects/project.jpg",
      "technologies": ["React", "Node.js"],
      "demoUrl": "https://...",
      "githubUrl": "https://github.com/..."
    }
  ]
}
```

**skills.json**
```json
{
  "skills": [
    {
      "category": "Frontend",
      "items": ["React", "JavaScript", "CSS3"]
    }
  ]
}
```

### Update Styling

Customize colors and styles in `tailwind.config.js`:

```javascript
module.exports = {
  theme: {
    colors: {
      primary: '#your-color',
      secondary: '#your-color'
    }
  }
}
```

## 🚀 Deployment

### Option 1: Netlify (Recommended)

```bash
# Build for production
npm run build

# Deploy to Netlify
# Option A: Drag and drop 'build' folder to Netlify Dashboard
# Option B: Use Netlify CLI
npm install -g netlify-cli
netlify deploy
```

**Features:**
- ✅ Automatic deployment on git push
- ✅ Free HTTPS SSL
- ✅ Custom domain support
- ✅ Form handling built-in

### Option 2: Vercel

```bash
# Install Vercel CLI
npm install -g vercel

# Deploy
vercel
```

**Features:**
- ✅ Automatic git integration
- ✅ Preview deployments
- ✅ Edge functions support
- ✅ Analytics included

### Option 3: GitHub Pages

```bash
# Update package.json
"homepage": "https://yourusername.github.io"

# Build and deploy
npm run build
npm install gh-pages --save-dev
npm run deploy
```

### Pre-Deployment Checklist

- [ ] Update personal information
- [ ] Add all project details
- [ ] Update social media links
- [ ] Test all links and forms
- [ ] Optimize images
- [ ] Run production build: `npm run build`
- [ ] Test production build locally
- [ ] Configure custom domain
- [ ] Set up email forwarding
- [ ] Enable analytics
- [ ] Set up SSL certificate

## 🤝 Contributing

Contributions are welcome! Here's how to contribute:

**1. Fork the Repository**
```bash
git clone https://github.com/Sheeba193/dev-portfolio.git
```

**2. Create Feature Branch**
```bash
git checkout -b feature/YourFeatureName
```

**3. Make Changes**
- Update content in `src/data/`
- Modify styles in `src/styles/`
- Enhance components in `src/components/`

**4. Commit Changes**
```bash
git commit -m "Add: Description of changes"
```

**5. Push to Branch**
```bash
git push origin feature/YourFeatureName
```

**6. Open Pull Request**

### Code Guidelines
- Follow React best practices
- Use functional components with hooks
- Maintain clean code structure
- Add comments for complex logic
- Test changes locally before pushing
